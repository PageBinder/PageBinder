# Keyboard shortcuts

| Action | macOS | Windows |
|---|---|---|
| Save | Cmd+S | Ctrl+S |
| New page | Cmd+N | Ctrl+N |
| New notebook | Cmd+Shift+N | Ctrl+Shift+N |
| Open notebook | Cmd+O | Ctrl+O |
| Search | Cmd+F | Ctrl+F |
| Undo / Redo | Cmd+Z / Shift+Cmd+Z | Ctrl+Z / Ctrl+Shift+Z |
| Delete selected object | Delete or Backspace with the object selected; Cmd+Shift+Backspace inside a text box | Delete; Ctrl+Shift+Delete inside a text box |
| Select the text box you are typing in | Escape | Escape |
| Bold / Italic / Underline | Cmd+B / Cmd+I / Cmd+U | Ctrl+B / Ctrl+I / Ctrl+U |
| Insert picture / file | Cmd+Shift+I / Cmd+Shift+A | Ctrl+Shift+I / Ctrl+Shift+A |
| Insert table | Cmd+Shift+T | Ctrl+Shift+T |
| Insert text box | Cmd+Shift+X | Ctrl+Shift+X |
| Copy / paste selected objects | Cmd+C / Cmd+V | Ctrl+C / Ctrl+V |
| Tab stop in text; indent in lists; next cell in tables | Tab (Shift+Tab reverses) | same |
| Page setup | Cmd+Shift+P | Ctrl+Shift+P |
| Print preview / Print | Cmd+Alt+P / Cmd+P | Ctrl+Alt+P / Ctrl+P |
| Export pages | Cmd+Shift+E | Ctrl+Shift+E |
| Page history | Cmd+Shift+H | Ctrl+Shift+H |
| Zoom in / out / reset | Cmd+= / Cmd+- / Cmd+0, or Ctrl+wheel, or pinch | Ctrl+= / Ctrl+- / Ctrl+0, or Ctrl+wheel |
| Page border / grid | Cmd+Shift+B / Cmd+Shift+G | Ctrl+Shift+B / Ctrl+Shift+G |
| Move between table cells | Tab / Shift+Tab; Tab in the last cell adds a row | same |
