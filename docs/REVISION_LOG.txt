PageBinder revision log
=======================

What changed in each version of PageBinder, newest first.

Every version opens, shows, edits, prints, and searches notebooks made by the
earlier ones. Nothing ever needs converting.


Version 1.1.4 - in development (not yet released)
-------------------------------------------------

Templates
- Pictures now show on template pages in the Templates notebook: pictures in
  a page saved as a template, pictures inserted while editing a template, and
  pictures in a template's text boxes. Before, only an empty frame showed.
  Pages made from a template always had their pictures.
- Templates are now always available in every notebook: Save as Template no
  longer asks whether a template is for one notebook only, and the Templates
  notebook shows one Global templates section. Templates saved for a single
  notebook by earlier versions are no longer shown or used (their files stay
  in that notebook's templates folder), and a section that used one as its
  default template now starts new pages blank. Pages already made from a
  template are not affected: each is its own copy.


Version 1.1.3 - 2 October 2026 (pre-release)
--------------------------------------------

Pictures
- A picture that was cut or copied can be pasted into a text box from the
  box's right-click menu (Paste picture), at the spot that was right-clicked.

Pages
- The page border and the grid are now settings of each page, kept with it:
  View > Toggle Page Border and View > Toggle Grid change only the page that
  is open, and the page remembers them. New pages start with the border on
  and the grid off, and a page made from a template takes the template's
  settings. Pages from earlier versions show the border and no grid, as
  before.
- With the border off, the page becomes one endless canvas: the gaps between
  sheets disappear and text runs on without breaks. Printing is unchanged and
  still breaks the text at each sheet.

Export
- The File menu's export item is now called Export Notebook (same dialog,
  same shortcut). Export This Page as PDF is removed from the File menu: the
  open page is saved as a PDF from Print Preview (Save as PDF), or from Export
  Notebook with "This page" chosen.
- File > Export Notebook > "Web page with attachments (.zip)" replaces the HTML
  file that only worked on this computer. It writes one .zip file holding a
  web page of the chosen pages with every picture and attached file, so it can
  be sent to anyone: unzipped anywhere, the .html file opens in any web
  browser without PageBinder, and its attachment cards open their files. The
  dialog explains what each format contains, and its drop-down lists no
  longer run past the dialog's edge.


Version 1.1.2 - 30 September 2026 (pre-release)
-----------------------------------------------

Pages and text
- New pages start with a title: the page's name in bold at size 20, with the
  date and time the page was made on the line below, in the computer's own
  date format. It is an ordinary text box that can be edited, moved, or
  deleted; click anywhere on the page to start writing. The name typed when
  the page is created goes into the title; renaming the page later leaves the
  title as it is. Pages made from a template are unchanged.
- Format painter: the paintbrush button in the toolbar copies the look of the
  text where the cursor is (font, size, colour, highlight, bold, italic,
  underline, strike-through) and paints it onto the next text you highlight,
  or the word you click. Painting a whole paragraph also copies its alignment
  and line spacing. Double-click the paintbrush to paint several times; press
  Escape or click the paintbrush again to stop. Undo reverses each paint.

Pictures
- Move a picture between the page and a text box with cut (or copy) and
  paste. Select a picture on the page, cut it, click in a text box, and
  paste: it goes into the box with text flowing beside it, keeping its size.
  Select a picture in a text box, cut it, click on the page, and paste: it
  sits on the page again. Pictures in text boxes also have Cut picture and
  Copy picture on their right-click menu, and any object on the page can now
  be cut (right-click > Cut, or Cmd+X / Ctrl+X). Text copied afterwards still
  pastes as text.

Notebooks and backups
- File > Notebook Properties shows when the notebook was last edited and by
  whom (the account name of the computer's user, recorded with each save),
  its size on disk and number of files, how much of that is page history,
  and the total size of all attachments of 50 MB or more, with the five
  largest listed.
- Verify Notebook explains itself: what the Quick and Full checks do, what
  each button does, and, for every problem it finds, what the problem means
  and what its repair will do.
- Page History shows each saved version as the whole page, including anything
  beside or below the paper, as the HTML backup copy does.
- New notebooks start with narrow margins (0.5 inch all round). Existing
  notebooks and their pages keep their margins, including pages added to them
  later.
- Each page's HTML backup copy (page.html, in the page's folder) now shows the
  whole page when opened in a web browser, including anything placed beside
  or below the paper, with the paper and its margins drawn behind it. Printed
  from the browser, it still gives the page exactly as PageBinder prints it. A
  page's copy is brought up to date the next time the page is saved.

Starting up
- PageBinder opens the notebook you used last, at the page you had open. If
  that page has since been deleted or renamed elsewhere, it opens the
  notebook's first page. The Welcome screen is still available from the
  notebook menu (Switch notebook).
- The button that removes a notebook from the Welcome screen's Recent list is
  now a small x beside the notebook instead of a wide band.

Search
- The text of emails dragged in from Outlook is now searchable. Many Outlook
  messages keep their text only in a formatted form, which search used to
  skip. The search index rebuilds itself once when a notebook is first opened
  in this version, so emails added earlier become searchable too.


Version 1.1.1 - 29 September 2026 (pre-release)
-----------------------------------------------

Page breaks and printing
- Text that runs past the bottom of a page now carries on line by line at the
  top of the next page's printable area. A long paragraph fills the page to
  its last line and continues over the page break, instead of the whole
  paragraph jumping to the next page.
- A list item, to-do item, heading, or quote whose first line would cross the
  page break moves to the next page whole, with its bullet or checkbox. A
  table moves over whole when it fits on one page.
- The page on screen now matches the printout exactly. Long paragraphs used to
  wrap a word or two differently on screen than on paper, and a table sat a
  little lower on screen than it printed.
- Print, Print Preview, and Save as PDF always use the current layout, even for
  a page last saved by an earlier version.

Editing
- Line spacing: choose 1.0, 1.15, 1.5 (standard), 2.0, 2.5, or 3.0 from the
  new control beside the font size, or highlight text, right-click, and choose
  Line spacing. It applies to every paragraph the highlight touches, and
  pressing Enter carries it into the next paragraph.
- Right-click > Line spacing > Default for new text boxes sets the spacing every
  new text box starts with on this computer.
- Stacking order: right-click any object (text box, picture, shape, line, or
  attachment card), or several selected objects, and choose Order to bring it
  to the front, bring it forward, send it backward, or send it to the back.
  Printing follows the same order, and Undo reverses it.
- Text alignment: the toolbar has four alignment buttons, Align left, Center,
  Align right, and the new Justify, which lines text up on both edges. The
  buttons have clearer symbols.
- The heading buttons (H1, H2, H3) and the heading shortcuts are removed.
  Headings already in a notebook still show and print as before.
- Highlighted text is no longer left highlighted after clicking somewhere else
  on the page, such as clear space, a picture, or another text box.
- Pictures in text boxes: right-click in a text box and choose Insert picture
  to place a picture at that spot. Dropping a picture file on a text box,
  pasting one while typing in it, or choosing Insert > Picture with the cursor
  in it puts the picture in the box too. Lines of text flow down beside the
  picture and continue underneath it. Drag the picture anywhere in the box,
  and drag any corner to resize it. It keeps its size when the text box is
  resized, moves with the text box, and prints exactly as shown. Select it and
  press Delete to remove it. Copying the text box to another page brings its
  pictures.


Version 1.1.0 - 25 September 2026 (pre-release, published 27 September 2026)
-----------------------------------------------------------------------------

Installers
- Installers for macOS (Apple silicon and Intel) and for Windows 10 and 11
  (x64 and ARM). The Windows installer needs no administrator rights.
- The installers are not yet signed, so macOS and Windows ask for confirmation
  the first time PageBinder is opened.
- Each new installation, including an update or a reinstall, that finds
  settings from an earlier one asks whether to keep them or start fresh.
  Starting fresh keeps the earlier settings in a backup folder. Notebooks are
  never affected either way.

Windows
- Saving waits and tries again when a virus scanner, the search indexer, or a
  backup program briefly holds a file open.
- Very deep folders and long file names (paths over 260 characters) work.
  Verify Notebook warns about paths that are getting close to the limit, for
  older backup tools.
- The right-click item for a file says Show in Explorer.
- Pictures in an exported HTML file now show when the file is saved outside the
  notebook.

Everywhere
- A notebook copied from another computer while it was open, for example in a
  network drive backup, now opens normally.
- Verify Notebook no longer reports the files Windows and macOS add to folders
  by themselves (Thumbs.db, desktop.ini, Icon).
- The page list shows a new page title straight away after saving, renaming,
  restoring a version, or creating a page from a template.
- The first time PageBinder starts, the Welcome screen shows a short Getting
  started note, and Create notebook suggests the Documents folder.

Search
- The text of PDF printouts is searchable. When a PDF is inserted as a printout,
  the text on its pages can be found by search, under In printouts, and the
  matching page of the printout is outlined. A document that is only attached,
  not printed out, is found by its name alone.

Help
- Help > Program description now explains what PageBinder does in plain terms,
  without development history.
- Getting started no longer repeats the installation steps: it starts from
  using the program.


Version 1.0.1 - 24 September 2026 (tested by hand; no installers)
-----------------------------------------------------------------

- The program is named PageBinder, with its own icon and logo. It was
  previously called DigiNote. Settings, the list of recent notebooks, and the
  global templates carry over by themselves.
- Tab with several list items highlighted moves them all to the right together,
  keeping their bullets or numbers, instead of erasing them. Shift+Tab moves
  them back.
- Lines and arrows have no fill colour, so their menus no longer offer one.
- The View menu has a single Toggle Full Screen item.


Version 1.0.0 - 24 September 2026 (first complete version; no installers)
-------------------------------------------------------------------------

Notebooks
- Notebooks in the style of the classic desktop OneNote: notebooks, section
  groups, coloured section tabs, and pages. Every notebook is an ordinary
  folder on your own disk or network drive, and nothing is sent anywhere.
- Every page also keeps a copy that opens in any web browser, so notes stay
  readable without PageBinder.
- A notebook of 50,000 pages opens in a few seconds, and search answers as you
  type.

Pages
- Each page is a free canvas: click to start a text box, and place text,
  tables, pictures, shapes, and attached files wherever you like.
- Pages are laid out on real sheets of paper (Letter, Legal, Tabloid, A4, A3,
  portrait or landscape) with margin presets, and print exactly as shown.
  Print Preview, printing, and export to one PDF or HTML file for a page, a
  section, or a whole notebook.
- Text: fonts, sizes, colours, highlighting, alignment, headings, and bulleted,
  numbered, and to-do lists. Tab works as in a word processor.
- Tables with row heights, column widths, cell colours, and borders like a
  spreadsheet, all from the cell's right-click menu. Copying cells into another
  table brings the content and keeps that table's look.
- Pictures, lines, arrows, rectangles, and ellipses.
- Any file can be attached, with no size limit. Saved emails show their
  subject, sender, and date, and their text can be searched. An attached PDF
  can be inserted as a printout of its pages.
- Copy and paste objects and whole pages, Insert signature, and Undo and Redo.

Safety
- Pages save themselves as you type, and every saved version of a page is
  kept: preview, restore, or copy any of them.
- Deleted pages, sections, and groups stay in Recycled Pages for 30 days.
- A damaged page is restored from its last good version automatically, and
  Verify Notebook checks a whole notebook and repairs what it safely can.
- The same notebook cannot be opened twice at once.

Templates
- Save any page as a template for one notebook or for every notebook, and give
  a section a default template. The Templates entry on the switch screen shows
  every template as a page you can edit.
